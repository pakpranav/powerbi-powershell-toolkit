# docs

Drop screenshots, architecture diagrams, or short write-ups here. Reference them from individual project READMEs with relative markdown image links, e.g.:

```markdown
![Dashboard screenshot](../docs/sample-dashboard-overview.png)
```

Keeping visuals here (rather than scattered across project folders) makes it easy for someone skimming the repo to see what things look like without opening Power BI or running a script.
